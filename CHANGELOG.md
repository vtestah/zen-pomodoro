## [1.0.0] - 2026-06-22

Initial baseline of the **Zen Pomodoro** focus fork (based on *Pomodoro Timer* by gfreeau).

### Features
- Calm focus timer with duration presets and a long-break cycle.
- Gentle on-screen cues: soft glow frame tracing progress, calm ending (no
  end-of-timer blinking), start ritual, optional full-screen Zen mode, and a
  breathing guide on breaks.
- Task list with pomodoro estimates, per-task progress, task templates, and a
  focus-task picker.
- Statistics dashboard: today / week / streak / all-time, hourly focus pattern,
  14-day bars, 12-week heatmap, by-task breakdown, milestones, and a
  finish-time estimate.
- Sounds: ticking, alerts, interval chime, ambient brown noise; Do Not Disturb
  while focusing.
- Daily goal + streak, flow extend, idle auto-pause, "Focus until…", and a
  panel progress ring.
- Configurable themes with live preview and full localization (Russian complete).
- Personal-build extras (not in the public package): distraction blocking and
  Pushover push notifications.
